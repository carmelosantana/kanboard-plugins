Never Haiku.

**Goal:** Ship Presence v1.0, a buildless Kanboard plugin that shows which project members are online, away or offline (with agent users shown as bots), plus the small Agents batch method it uses.

**Architecture:** A `presence` table holds one row per user. Rows are written by three throttled paths: a web recorder (`onStartup`), a JSON-RPC middleware (agents) and a heartbeat route (visible tabs). `PresenceModel::lineup()` turns a project's members plus their rows into states in one query. A project-header strip and a heartbeat script render the states, and the script dispatches a `presence:update` DOM event that themes (Battle Lobby) consume without overriding templates.

**Tech Stack:** PHP 8.4, Kanboard 1.2.47 plugin API (PicoDb, hooks, routes, JsonRPC middleware), vanilla JS (no build), CSS, PHPUnit through `testing/run-plugin-tests.sh`.

**Spec:** `docs/specs/2026-10-07-presence-v1-design.md` (wayfinder map Kanboard #5467)

## Global Constraints

- Kanboard `>=1.2.47`, PHP `>=8.4`; SQLite, MySQL and Postgres all supported (schema in all three).
- Plugin name `Presence`; namespace `Kanboard\Plugin\Presence`; repo `carmelosantana/kanboard-presence`; working folder `kanboard-plugins/Presence` (its own git repo, branch `main`).
- Version `1.0.0` must match across the tag, `plugin.json` and `getPluginVersion()`.
- `plugin.json`: `"requires": []`, `"recommends": [{"name": "Agents", "version": ">=0.4.0"}]`.
- Thresholds are constants: online = heartbeat within 120 s; away = any activity within 900 s; agent online = API activity within 300 s; poll 60 s; idle backoff to 300 s after 1800 s with no input. Web writes are throttled at 30 s, API writes at 60 s, heartbeat writes at 30 s.
- Stored data is `user_id`, `last_seen`, `last_beat` and `source` only. No page, project, IP or user-agent data.
- CSP forbids inline script, so JS config travels in `data-*` attributes.
- No `setTemplateOverride`. Hooks only.
- Agents changes ship as Agents `0.4.0` (in the `Agents` repo).
- Ticket references are written as `Kanboard #N`.

## Review Focus

1. **Hidden user still visible as online through the API path.** If a user turns on "Appear offline" while an agent token or a stale row exists, they must read *offline* immediately, both in the lineup and in writes. Pinned in Task 4 (`testHiddenUserReadsOfflineEvenWithFreshRow`) and Task 3 (`testHiddenUserIsNotWritten`).
2. **Heartbeat for a project the viewer can't access.** A crafted `project_id` must not leak the member list. Expect 403 and no lineup. Pinned in Task 6 (`testBeatForForeignProjectIsForbidden`).
3. **App-token (`jsonrpc`) API calls.** These have no user and must not write a row for uid 0 or crash. Pinned in Task 5 (`testAppTokenCallWritesNothing`).
4. **Disabled or deactivated members.** A user with `is_active = 0` (for example a disabled agent) must drop out of the lineup, even with a fresh row. Pinned in Task 4 (`testInactiveUserIsExcluded`).
5. **Presence disabled by an admin.** No writes, no strip, no script and an empty beat response. Pinned in Task 3 (`testDisabledInstanceWritesNothing`) and Task 6 (`testBeatWhenDisabledReturnsEmpty`).

    public function setHidden(int $userId, bool $hidden): void

```php
<?php
namespace Kanboard\Plugin\Presence\Model;

use Kanboard\Core\Base;

// One row per user, updated in place. Throttles are conditional UPDATEs (portable across
// SQLite/MySQL/Postgres); first sight INSERTs and swallows a racing duplicate.
class PresenceModel extends Base
{
    const TABLE = 'presence';
    const ONLINE_WINDOW = 120;
    const AWAY_WINDOW = 900;
    const AGENT_WINDOW = 300;
    const WEB_THROTTLE = 30;
    const API_THROTTLE = 60;
    const BEAT_THROTTLE = 30;
    const SOURCE_WEB = 'web';
    const SOURCE_API = 'api';

    public function touch(int $userId, string $source, bool $beat = false, ?int $now = null): bool
    {
        $now = $now ?? time();
        $settings = new PresenceSettings($this->container);
        if ($userId <= 0 || ! $settings->isEnabled() || $settings->isHidden($userId)) {
            return false;
        }
        $source = $source === self::SOURCE_API ? self::SOURCE_API : self::SOURCE_WEB;

        if ($beat) {
            $sql = 'UPDATE '.self::TABLE.' SET last_seen = ?, last_beat = ?, source = ? WHERE user_id = ? AND last_beat < ?';
            $params = [$now, $now, $source, $userId, $now - self::BEAT_THROTTLE];
        } else {
            $throttle = $source === self::SOURCE_API ? self::API_THROTTLE : self::WEB_THROTTLE;
            $sql = 'UPDATE '.self::TABLE.' SET last_seen = ?, source = ? WHERE user_id = ? AND last_seen < ?';
            $params = [$now, $source, $userId, $now - $throttle];
        }

        $stmt = $this->db->execute($sql, $params);
        if ($stmt !== false && $stmt->rowCount() > 0) {
            return true;
        }
        if ($this->db->table(self::TABLE)->eq('user_id', $userId)->exists()) {
            return false; // throttled
        }

        try {
            return (bool) $this->db->table(self::TABLE)->insert([
                'user_id' => $userId,
                'last_seen' => $now,
                'last_beat' => $beat ? $now : 0,
                'source' => $source,
            ]);
        } catch (\Exception $e) {
            return false; // concurrent first write won the race
        }
    }
}
```

    public function state(?array $row, bool $isBot, bool $hidden, int $now): string
    {
        if ($row === null || $hidden) {
            return 'offline';
        }
        if ($isBot) {
            return (int) $row['last_seen'] >= $now - self::AGENT_WINDOW ? 'online' : 'offline';
        }
        if ((int) $row['last_beat'] >= $now - self::ONLINE_WINDOW) {
            return 'online';
        }
        return (int) $row['last_seen'] >= $now - self::AWAY_WINDOW ? 'away' : 'offline';
    }

    public function lineup(int $projectId, int $viewerId, ?int $now = null, ?AgentDetector $agents = null): array
    {
        $now = $now ?? time();
        $ids = array_map('intval', array_keys($this->projectUserRoleModel->getAllUsers($projectId)));
        if ($ids === []) {
            return [];
        }

        $users = $this->db->table('users')
            ->columns('id', 'username', 'name', 'email', 'avatar_path')
            ->in('id', $ids)->eq('is_active', 1)->findAll();
        $activeIds = array_map('intval', array_column($users, 'id'));
        $rows = [];
        foreach ($this->db->table(self::TABLE)->in('user_id', $activeIds ?: [0])->findAll() as $r) {
            $rows[(int) $r['user_id']] = $r;
        }
        $bots = array_flip(($agents ?? new AgentDetector($this->container))->agentIds($activeIds));
        $hidden = array_flip(array_map('intval', $this->db->table('user_has_metadata')
            ->in('user_id', $activeIds ?: [0])->eq('name', PresenceSettings::META_HIDDEN)->eq('value', '1')
            ->findAllByColumn('user_id')));

        $order = ['online' => 0, 'away' => 1, 'offline' => 2];
        $out = [];
        foreach ($users as $u) {
            $id = (int) $u['id'];
            $isBot = isset($bots[$id]);
            $out[] = [
                'user_id' => $id,
                'name' => $u['name'] !== '' && $u['name'] !== null ? $u['name'] : $u['username'],
                'username' => $u['username'],
                'email' => (string) $u['email'],
                'avatar_path' => (string) $u['avatar_path'],
                'state' => $this->state($rows[$id] ?? null, $isBot, isset($hidden[$id]), $now),
                'is_bot' => $isBot,
                'is_self' => $id === $viewerId,
            ];
        }
        usort($out, fn ($a, $b) => [$order[$a['state']], strtolower($a['name'])] <=> [$order[$b['state']], strtolower($b['name'])]);
        return $out;

<?php
namespace Kanboard\Plugin\Presence\Model;

use Kanboard\Core\Base;

// Runs on every web request (app.bootstrap). The session timestamp keeps most requests off the DB.
class WebRecorder extends Base
{
    const SESSION_KEY = 'presence_last_write';

    public function record(?int $now = null): bool
    {
        $now = $now ?? time();
        if (! $this->userSession->isLogged()) {
            return false;
        }
        $last = (int) (session_get(self::SESSION_KEY) ?? 0);
        if ($last > $now - PresenceModel::WEB_THROTTLE) {
            return false;
        }
        session_set(self::SESSION_KEY, $now);
        return (new PresenceModel($this->container))->touch($this->userSession->getId(), PresenceModel::SOURCE_WEB, false, $now);
    }
}

`Assets/js/presence.js`:

```js
// Presence heartbeat: one POST per visible tab per minute; backs off when idle; pauses when hidden.
// Config comes from #presence-mount data-* (CSP forbids inline script). Themes listen for 'presence:update'.
(function (window, document) {
  'use strict';
  var BEAT = 60000, IDLE_BEAT = 300000, IDLE_AFTER = 1800000;

  function nextDelay(s) {
    if (!s.visible) return null;
    return s.idleMs > IDLE_AFTER ? IDLE_BEAT : BEAT;
  }

  function applyLineup(root, data) {
    var byId = {};
    (data.members || []).forEach(function (m) { byId[String(m.user_id)] = m; });
    var plates = root.querySelectorAll('.presence-plate');
    for (var i = 0; i < plates.length; i++) {
      var m = byId[plates[i].dataset.userId];
      if (!m) continue;
      plates[i].dataset.presence = m.state;
      plates[i].dataset.bot = m.is_bot ? '1' : '0';
    }
  }

  function start() {
    var mount = document.getElementById('presence-mount');
    if (!mount) return;
    var strip = document.querySelector('.presence-strip');
    var projectId = mount.dataset.projectId || (strip && strip.dataset.projectId) || '';
    var lastInput = Date.now(), timer = null;

    function schedule() {
      clearTimeout(timer);
      var d = nextDelay({ visible: document.visibilityState === 'visible', idleMs: Date.now() - lastInput });
      if (d !== null) timer = setTimeout(beat, d);
    }

    function beat() {
      var body = new FormData();
      body.append('csrf_token', mount.dataset.csrf);
      if (projectId) body.append('project_id', projectId);
      fetch(mount.dataset.beatUrl, { method: 'POST', body: body, credentials: 'same-origin', headers: { 'X-Requested-With': 'XMLHttpRequest' } })
        .then(function (r) { return r.ok ? r.json() : null; })
        .then(function (data) {
          if (data && data.enabled && data.project_id) {
            if (strip) applyLineup(strip, data);
            document.dispatchEvent(new CustomEvent('presence:update', { detail: { project_id: data.project_id, members: data.members } }));
          }
        })
        .catch(function () {})
        .then(schedule);
    }

    function onInput() {
      var wasIdle = Date.now() - lastInput > IDLE_AFTER;
      lastInput = Date.now();
      if (wasIdle) schedule();
    }

    document.addEventListener('visibilitychange', function () {
      if (document.visibilityState === 'visible') beat(); else clearTimeout(timer);
    });
    document.addEventListener('pointerdown', onInput, { passive: true });
    document.addEventListener('keydown', onInput);
    beat();
  }

  window.KBPresence = { nextDelay: nextDelay, applyLineup: applyLineup, start: start };
  if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', start); else start();
})(window, document);
```
